# イライラ棒用タイマー

Python / Tkinter / pygameを使用して開発した、イベント向けのイライラ棒用タイマーです。

## 概要

科学イベントで使用することを目的に開発しました。
実際のイベントで使用しており、クリアタイムの計測やランキング表示などを行います。

## 主な機能

- クリアタイムの計測
- 自動ランキング表示
- 計測中のBGM再生

## 使用技術

- Python
- Tkinter
- pygame

## 開発背景

イベントでの運用を想定し、計測機能に加えてランキング表示やBGM再生など、イベントを盛り上げる機能を実装しました。
実際の使用時のフィードバックをもとに、BGM再生機能を追加しています。

## 実行方法

### Pythonから実行

必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

アプリケーションを実行します。

```bash
python Timer.py
```

### exeファイルのビルド

PyInstallerを使用してexeファイルを生成できます。

```bash
pyinstaller Timer.spec
```

生成されたexeファイルは `dist` ディレクトリ内に配置されます。

## 注意事項

- BGM再生にはpygameを使用しています。
- 使用する音声ファイルを同梱しています。
